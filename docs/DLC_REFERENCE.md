# DLC 设计参考：借鉴其他游戏（2026-08-16）

> 目的：为 8 个独立 DLC（大航海/一战/无线电/二战/飞天魔法/帝国/教国/2077）从成熟游戏里找可借鉴的
> **具体机制**，并映射到本框架的注册面（系统/命令/策略卡/科技/建筑/物品/事件/scripts）。
> 诚信声明：本轮 web 检索工具暂时不可用（API 认证失败），以下参考来自既有游戏机制知识
> （RimWorld/大航海时代/钢铁雄心/十字军之王/Cyberpunk 2077 等），条目均可按链接展开人工复核。
> 与本项目精神一致的取舍：一切皆抽卡、神谕不碰选择链、DLC 相互独立——参考机制落到"加内容/加
> 可选玩法轴"，不改变生存循环，不做强制叙事。

## 0. 总纲：RimWorld 的 DLC 模式（本游戏的同族参考）

RimWorld（边缘世界）本身就是一个"小人求生模拟 + 全 mod 化"的游戏，其 4 个官方 DLC 是
**独立 DLC = 一条新玩法轴**的最佳范本，与本项目的插件化纪律同构：

| RimWorld DLC | 玩法轴 | 我们的对应 DLC |
|---|---|---|
| Royalty（贵族/灵能） | 灵能等级：冥想充能→消耗灵能施法，等级解锁 | 飞天魔法 |
| Ideology（意识形态） | 戒律/仪式/膜拜建筑影响心情与行为 | 教国 |
| Biotech（生物科技） | 基因/仿生体部件替换，属性增减 | 2077 义体 |
| Anomaly（异象） | 事件驱动玩法（调查/收容） | （后续任意事件 DLC） |

**借鉴结论：每个 DLC 只贡献一条"可选的机制轴"，不碰核心生存循环**——与本项目"玩法包
= registerSystemDef/命令/数据表"的插件化纪律完全一致。

## 1. 大航海 → 参考《大航海时代II》《Anno 1800 远征》

- **远征任务（expedition）**：小队离营出海 → 多阶段事件（每阶段打一张事件卡，骰面决定
  遭遇/收获）→ 归队带回特产。`Anno 1800` 的远征是纯事件卡流，零实时操作。
  - 本框架落地面：`dlc:sail` 系统（离营远征 = 类似征召但离开地图，消耗食物，阶段事件
    resolve 随机结果 + 归队带物品）；`declaredEvent` 已支持事件表（风暴/海盗/迷航）。
- **贸易差价**：跑商 = 不同营地产出 → 卖出买进赚差价（`trade` 包已有 rate 基础）。
  - 落地面：南巡令策略卡 → 出海南巡 = 远征 + 贸易；特产物品 + 交易事件。
- 已有基础：罗盘/帆布/造船坞（轻帆船科技门控）/海盗。缺的机制轴 = **"离营远征"**。

## 2. 一战 → 参考《钢铁雄心4》后勤/堑壕

- **堑壕 = 防线 + 驻守加成**：钢铁雄心里战壕等级越高，防守方损失越小；占据防线单位
  获得"驻守"加成。
  - 落地面：`dlc:trench` 建筑已有（tags defense）→ 加一条系统规则：驻守（停留在堑壕
    格）的小人对来袭敌人伤害减免，或"战壕状态"写入 pawn.extra。
- **补给断供即弱化**：弹药/食物不足 → 参战单位战力/士气下滑（钢铁雄心断 supply 即
  伤亡飙高）。
  - 落地面：战斗消耗**弹药物品**（新物品 `dlc:ammo`）：无弹药 → 攻击伤害减半；总攻令
    策略卡前先确保补给——**资源-决策联动**，完全数据驱动。
- **总攻 = 批处理征召 + 攻击指定**：`draft` + `attack {hostileIndex}` 命令均已存在，
  总攻令 = 一键征召全部 + 指定目标（纯命令组合，零新系统）。

## 3. 无线电 → 参考《Frostpunk 信号塔》+ RimWorld 通信台

- **广播调士气**：Frostpunk 发明"宣传"法令后，无线电广播可全体心情 +；频段选择还有
  附加效果。
  - 落地面：`dlc:radio-tower` 已有 → 系统每 N 秒广播一次，全体心情小幅 +（比事件更稳定
    的"持续光环"，aura 已支持同类）；"陌生波段的消息"事件已有。
- **呼叫 = 援助/贸易频道**（RimWorld 通信台：呼叫增援、请求贸易）。
  - 落地面：呼叫令策略卡 → 冷却后随机援助（友方单位/物资包裹/商队来访），`declare
    Event` 或系统撮合。
- 已有基础：无线电台/电台塔（无线电科技门控）/呼叫令。缺的机制轴 = **"持续广播 + 呼叫
  援助"**。

## 4. 二战 → 参考《Company of Heroes》装甲 + 炮火

- **区域延迟轰炸**（CoH 炮击：指定区域→几秒后打击）：
  - 落地面：`dlc:barrage` 命令（已有）→ 指定区域 → `dlc:ww2` 系统延迟 3s 后对区域内
    敌人造成伤害（定位+延时,无需实时操作,契合"不碰选择链"——玩家只下目标）。
- **装甲 = 高防慢速**（坦克 vs 步兵定位区分）：
  - 落地面：`dlc:armor` 敌人已有（hp 高/速慢）→ 加"集群编队"（袭击模板可含混合兵种）；
    玩家侧载具暂缓（工程量）。
- **炮台自动还击**：`dlc:turret` 已有 → 系统规则：攻击射程内敌人的来袭单位自动掉血
  （防御工事数据化，参考 RimWorld 炮塔）。

## 5. 飞天魔法 → 参考 RimWorld Royalty 灵能 + 英雄无敌

- **冥想充能 → 消耗施法**（Royalty 灵能：冥想攒灵能值 → psycaster 消耗施法，等级解锁
  高级法术）：
  - 落地面：`dlc:meditate` 工作（registerWork，魔法塔内进行）→ 攒法力
    （pawn.extra.mana 随档）；施法 = 命令/策略卡消耗法力：
    浮空（跳过水格/加速）、闪现（瞬移）、治疗小伤。**一切皆抽卡**：施法卡进卡池由权重
    调制，法力是硬约束（没有法力就抽不到施法卡）。
- **魔法塔 = 冥想房 + 法力池**：`dlc:mage-tower` 已有 → 关联法力恢复速度（aura 或
  系统）。
- 幼龙 = 袭击变体（已有 enemy）。

## 6. 帝国 → 参考《文明》奇观 + RimWorld 派系

- **奇观光环**（文明：奇迹提供全局加成）：`dlc:palace` 已有（皇宫）→ 玩家建成 = 全营
  心情/工作效率加成（aura 或系统检测）。
- **拓殖 = 蓝图副作用**（已有机制：策略卡 blueprint → 新营地）：
  - 落地面：拓殖令 = 帝国版"开拓令"→ 蓝图新篝火；铸币 = 贸易货币关联
    （`dlc:coin` 已有,trade 包 rate 联动）。
- **民怨 → 叛军事件**：经济/心情低落到阈值 → `dlc:rebel` 袭击事件（事件条件谓词
  registerEventPredicate,参考 totem 的 hasTotem 先例）。

## 7. 教国 → 参考《十字军之王3》教条 + RimWorld Ideology

- **教条/戒律 = 卡权重调制**（CK3 教条塑造信仰行为）：
  - 落地面：教国包用 **markov/seriesDesires/策略卡权重**调制行为——如挂"圣战令"期间
    狩猎权重 ×3；"斋戒日"→ 休憩权重 ×2（不插卡槽、不碰选择链,正是本项目引导语义）。
- **仪典 = 定时集体仪式**（Ideology 仪式：攒够气氛/人数 → 大心情加成）：
  - 落地面：`dlc:ceremony` 系统：每 300s 在大教堂发起仪式事件,参与者心情 +（事件
    effects 已支持 mood）。
- **朝圣 = 长距离任务**（CK3 朝圣）：同大航海远征机制（离营带补给 → 事件 → 归队带
  圣物/信仰加成）。教国与大航海在此共享"离营任务"机制轴（独立包各自实现,互不依赖）。
- 已有基础：圣典/大教堂（神学科技门控 + aura）/圣战令/异端。

## 8. 2077 义体 → 参考 Cyberpunk 2077 本体 + Deus Ex + RimWorld Biotech

- **斯安威斯坦 = 主动技（时间减速/反应加速）**（Cyberpunk 2077：启用后主观时间变慢，
  冷却制）：
  - 落地面：`dlc:install-cyber` 命令已装义体 → `dlc:cyber` 系统把"启用"做成**主动技**：
    `dlc:sandevistan` 命令 → 未来 5s 攻速/闪避加成,60s 冷却（pawn.extra.cyberActive +
    until,随档）。斯安威斯坦从"占位状态"变成**有真实战斗价值的义体**。
- **义体容量/过热**（Deus Ex 能量、RimWorld Biotech 仿生体部件制）：
  - 落地面：义体值 = 100（tuning 可调）,每装一个占容量,物品 meta 表声明占用
    （`meta.cyberCost`）——未来多义体时代的价格约束,先留 tuning 位。
- **义体医生 = 服务建筑**（已有 `dlc:ripperdoc`,义体技术科技门控）+ 义体强化令。
