## 原则：DLC = 种子库，不设计机制链

- **DLC 提供种子**：物品 / 建筑（含 arena/aura/tech 门控）/ 科技 / 敌人 / 事件（declaredEvent）/
  卡 / 策略卡（含 blueprint 蓝图）/ 工作（registerWork）/ 命令（直接指挥，与 move/mine/assign 同类）。
- **不做机制链**：无主动技计时、无延迟轰炸撮合、无任务系统、无资源硬约束规则、无门槛/民怨阈值。
- **玩法 = 模拟涌现**：卡池权重 → 行为倾向；事件随机 → 故事；生存压力 + 物资/科技门控 →
  决策；玩家通过基础命令（移动/建造/征召/降旨/指派）自然干预——**系统只掷骰，复杂行为由
  卡池与事件涌现**（一切皆抽卡；神谕只引导不碰选择链）。
- **参考游戏的用途**：只用来**选择种子**与启发构图（哪些元素放进去能让涌现有趣），不照搬机制。

## 0.1 矮人要塞参照（review 标尺，2026-08-16）

用户指定《矮人要塞》为参照重新 review DLC 线。DF 是"深度模拟 + 涌现叙事"的祖师爷，逐条对照：

| DF 原则 | 本项目已内建的基底 | DLC 线对齐结论 |
|---|---|---|
| **无胜负（losing is fun）** | 无目标/无结算；死亡与灾变是叙事不是失败（回放：3 人阵亡是故事） | ✅ DLC 无目标机制；策略卡=引导、事件=随机故事，不加胜负/评分 |
| **深度模拟即故事** | 卡池决策/需求/社交/熟练度 = 个体深度模拟；事件因局面触发（谓词），不是脚本线 | ✅ DLC 只加种子；"总攻令"不引爆战争，战争由敌人/地形/玩家命令涌现 |
| **记忆与传闻** | `socialSystem` 已内建 **heard-stance 传闻层**：`pawn.knownFires[篝火].stance`——"听说对方营地有敌意历史→敌意"优先于数值关系；篝火历史由 historyRecent 沉淀（模拟里的"故事"活在传闻里） | ✅ 基底已有，DLC 无需新机制；未来方向：DLC 事实（义体/圣典/探险）也可被"听说"引用——只加事件文本/事实标记，不加规则 |
| **工匠杰作与命名** | 熟练度（mastery）驱动卡权重演化（卡=习惯）；「技能精进」事件已有 | ⚠️ **缺口**：无 DF 式"杰作/命名物品"（artifact）。未来种子建议：一张「工匠杰作」事件——高熟练产出时触发，产出**带名字与制造者的物品**（物品 meta 记制造者，仅事件+物品，零机制链）；玩法由社交系统自然涌现（夸赞/羡慕/嫉妒——socialSystem 已处理这类互动） |

**review 结论**：
1. 无机制链残留需要移除（首轮已全降为种子）。
2. 2077 的 `dlc:cyber`（每 60s 叙事）保留：极简叙事点，不改变数值/行为，不违背种子原则。
3. 唯一值得补的 DF 式种子 = 「工匠杰作」（事件+命名物品），属核心层通用种子，与具体 DLC
   无关——列为建议，不做机制链，等有具体内容需求时按"事件表 + 物品"加。
4. 传闻层是现成的高价值涌现面：未来做任何"值得被记住"的 DLC 种子（义体、圣典、杰作），
   都应顺路让它在社交传闻里可被引用（cost 极低：事件文本 + 事实标记）。

## 0. 总纲：RimWorld 的 DLC 模式（种子视角）

RimWorld 官方 DLC 的价值不在机制复杂度，而在**一组种子把玩法轴线点亮**：

| RimWorld DLC | 种子（构件） | 我们的对应 DLC |
|---|---|---|
| Royalty（灵能/贵族） | 冥想工作 + 灵能等级卡 + 专用建筑 + 新派系 | 飞天魔法（冥想工作 + 魔法塔 + 幼龙） |
| Ideology（意识形态） | 膜拜建筑 + 仪式事件 + 戒律卡权重 | 教国（大教堂 + 祭典事件 + 圣战令） |
| Biotech（生物科技） | 仿生体物品 + 服务建筑 + 基因 | 2077 义体（斯安威斯坦物品 + 义体医生诊所） |
| Anomaly（异象） | 事件表 + 调查/收容构件 | 后续任意事件 DLC |

## 1. 大航海 —— 种子：造船坞/帆布/罗盘/海盗/南巡令

- 种子：`dlc:shipyard` 造船坞（轻帆船科技门控 + 高成本）+ `dlc:sailcloth`/`dlc:compass` 物品 +
  `dlc:pirate` 海盗敌人 + `dlc:sail-south` 南巡令（策略卡，走 walkAndWork 引导）。
- 涌现：科技抽卡抽到「轻帆船」→ 解锁造船 → 全营为高成本奇观忙碌 → 新物品/产出进入卡池与
  交易；海盗敌人改变袭击构成。**航海内容 = 门控解锁的建造/物品流，无任务系统**（离营远征
  机制已移除）。

## 2. 一战 —— 种子：步枪/钢盔/堑壕/战马/总攻令

- 种子：`dlc:rifle`/`dlc:helmet` 物品 + `dlc:trench` 堑壕（tags defense、不可通行 → 天然掩体/
  布防格局）+ `dlc:cavalry` 战马敌人 + `dlc:assault` 总攻令（策略卡工作引导）。
- 涌现：堑壕作为不可通行建筑改变寻路与交战面；战马来袭改变袭击节奏；玩家用**已有基础命令**
  （征召 + 右键攻击）形成防线——「堑壕战」的战术感从地形构件涌现，无需弹药/士气规则
  （弹药断供机制已移除）。

## 3. 无线电 —— 种子：电台/电台塔/呼叫令/陌生波段事件

- 种子：`dlc:radio` 电台物品 + `dlc:radio-tower` 电台塔（无线电科技门控 + capabilities）+
  `dlc:radio-call` 呼叫令（策略卡）+ `dlc:radio_msg` 「陌生波段的消息」事件（declaredEvent，
  effects.mood）。
- 涌现：事件表随机触发的波段消息成为叙事点缀（谁在发报？）；电台塔建成后光顾/事件频率变化。
  **广播技能、呼叫援助频道等系统机制已移除**——通信氛围由事件涌现。

## 4. 二战 —— 种子：特种钢/炮台/装甲车/炮火令

- 种子：`dlc:steel` 物品 + `dlc:turret` 炮台（装甲战争科技门控、高防不可通行 → 防御支点）+
  `dlc:armor` 装甲车敌人（高防慢速） + `dlc:barrage` 炮火令（策略卡工作引导）。
- 涌现：装甲车引发"需要高防支点对抗"的防守抉择；炮台成为布防重心。**延迟轰炸撮合机制
  已移除**——炮火令只是引导工作的策略卡，战争强度由敌人构成涌现。

## 5. 飞天魔法 —— 种子：扫帚/水晶/魔法塔/幼龙/冥想工作/飞天令

- 种子：`dlc:broom`/`dlc:mana-crystal` 物品 + `dlc:mage-tower` 魔法塔（飞行术科技门控 + aura）+
  `dlc:drake` 幼龙敌人 + `dlc:meditate` 冥想工作（registerWork，魔法塔内） + `dlc:fly` 飞天令
  （策略卡）。
- 涌现：冥想作为工作卡进卡池——**小人自己决定想不想冥想**（想偷懒/想清净就抽到）；
  冥想卡效用（恢复/心情）由卡表驱动；魔法塔 aura 提供环境加成。**法力池/施法消耗等
  硬约束机制已移除**——魔法氛围 = 冥想工作 + 魔法塔 + 龙，行为交给卡池涌现。

## 6. 帝国 —— 种子：铸币/丝绸/皇宫/拓殖令/叛军

- 种子：`dlc:coin`/`dlc:silk` 物品 + `dlc:palace` 皇宫（帝国法统科技门控、奇观级成本）+
  `dlc:colony` 拓殖令（策略卡 + blueprint 新营地——已有 oracle:migrate 先例）+ `dlc:rebel` 叛军敌人。
- 涌现：皇宫奇观掀起全员建造潮；拓殖令蓝图 → 新营地分家；叛军袭击在扩张后出现。
  **民怨阈值机制已移除**——叛军何时来交给事件表/袭击节奏。

## 7. 教国 —— 种子：圣典/大教堂/圣战令/异端/祭典事件

- 种子：`dlc:tome` 物品 + `dlc:cathedral` 大教堂（神学科技门控 + aura 心情光环）+
  `dlc:crusade` 圣战令（策略卡，狩猎权重 ×3——与伐木令同款"引导非指令"）+
  `dlc:heretic` 异端敌人 + `dlc:ceremony` 祭典事件（declaredEvent，effects.mood——totem 先例）。
- 涌现：大教堂 aura 让营地心情回暖；祭典事件随机套 → 集体仪式感；圣战令 = 神谕目标权重
  调制，不插卡槽、不碰选择链。**仪式调度/戒律系统已移除**——信仰氛围由建筑光环 + 事件 +
  策略卡涌现。

## 8. 2077 义体 —— 种子：斯安威斯坦物品/义体医生诊所/义体强化令/无人机/装义体命令

- 种子：`dlc:sandevistan` 斯安威斯坦物品 + `dlc:ripperdoc` 义体医生诊所（义体技术科技门控）+
  `dlc:chrome-up` 义体强化令（策略卡）+ `dlc:dron` 巡逻无人机敌人 + `dlc:install-cyber` 命令
  （给小人装义体 = 写 pawn.extra.cyber，**与 move/mine/assign 同类的直接指挥**）+
  `dlc:cyber` 系统（每 60s 义体携带者触发叙事事件，仅叙事）。
- 涌现：义体作为状态随小人存在——装过没装过成为卡池/事件的**可引用事实**（后续 DLC 可加
  "义体保养卡""义体炫耀"交互）；装义体是玩家的一次性直接干预，之后小人带着义体过日常，
  故事由此长出来。**主动技/战斗 buff/过热容量等机制已移除**——义体是事实 + 叙事，战力交给
  模拟涌现。
