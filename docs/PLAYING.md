# infcanvas · 当前版本玩法说明（v0.1 · 单机 P0）

> 面向玩家的一页纸。想了解设计理念/架构看 `docs/DESIGN.md`，这里是**怎么玩**。

## 这是什么

一个会自动运转的殖民地模拟：一群小人会**自己**伐木、采矿、建造、祈祷、聊天、打架。
你主要是个**观察者 + 神谕**——偶尔下场帮一把、或者只管看戏。

## 开局你就该看到

- 屏幕中央 4 个小鼠人在**自动活动**（砍树/采矿/闲逛），下方篝火是你们的**部落营地**。
- 顶部资源条：🌲木头 · 🪨矿 · 🍖食物 · 🛠️工具 · 👥人数 · ☀️/🌙昼夜 · 天气。
- 小人会自动扩张营地：缺粮建农田、缺工具建工作台、没矿建矿洞、信仰高了建教堂。
- 如果开局是**空世界/一个人都没有** → 是旧存档坏了，刷新页面会自动重开一局。

| 调速/暂停 | 左下角 ⏸ / 1x / 2x / 3x，或空格 / 1/2/3 |

## 关键玩法点

### 小人是自主的，别急着指挥
他们靠"抽卡"自决（3 选 1 择优），会疲劳、会饿、会闹脾气、会违抗安排。
你选中一个小人，面板会显示他刚才"闪念"了什么、为什么这么选。

### 指派职业（分工）
选中小人 → 面板点 **伐木工/矿工/农民/工匠**，他就专心干那行（生产线雏形）。
> （2026-08-12 更新：另有**渔民**职业——在竹筏上持续捕鱼产食物，见下方专节）
想恢复自由，点"自由"。

### 派系与战争（篝火 = 独立势力）
- **每个篝火 = 一个独立派系**，有自己的名字、部落记忆、对邻居的看法。
- 派系间会自动：**贸易**（友好时）、**传话**（关系一般时）、**袭击/吞并**（敌对时）。
- 点底部"🌍 派系"面板看全世界的势力网络；选篝火建筑可看它的记忆和看法。

### 教堂与神谕
- 信仰足够高时，AI 会**自动建教堂**（2x2，紫色）。
- 选中教堂 → 点"✨ 发布神谕" → 祝福附近的高信仰小人（30 秒心情加成）。
- 你**不能直接指挥**，只能通过神谕影响高信仰者——这是"神谕不碰选择链"的设定。

### 生存压力
- 野狼会**周期性袭击**！受伤要及时到篝火边疗伤；建墙保护营地。
- 食物会耗尽 → 尽早建农田；矿/木头要持续采。
- 小人会饿死/战死；若**全部团灭**，神谕会自动**附身**到其他存活派系继续。

### 神谕抽卡（策略卡 + 科技）
- 神谕每隔一阵**印策略卡**（顶部紫色横幅「神谕降旨」）：缺粮时降「垦田令」（自动规划农田）、人丁兴旺时降「拓荒令」（远处建新营地 → 新派系）。
- **科技 = 抽卡解锁**：神谕会不定期抽科技卡（竹筏工艺 → 桥梁工程 → 造船术）；**木桥/渡船**需对应科技才可建造（建造菜单 🔒 灰显），**竹筏开箱可建**（渔民生计起步）。
- 建造菜单底部「水路」分组：**竹筏**（水面平台，渔民站筏捕鱼）、**渡船**（2×2 大平台）、**木桥**（把水面修成可通行的桥面，改地形 z=1）。

### 指派渔民
选中小人 → 面板点 **渔民**，他会去竹筏上持续捕鱼（产出食物）。

### 突发事件
游戏会不定期冒出事件（流浪者加入、丰收、矿脉、瘟疫、游商、庆典……），
这些事件只会出现在**符合当前状况**时（有余粮才有流浪者、有农田才丰收）。

## 常见疑问

- **为什么小人不动？** 确认没暂停（看左下角是否 ⏸）；空世界请刷新重开。
- **怎么重开新局？** 目前自动存档每 30 秒写入浏览器；清空站点数据可重开。
- **能联机吗？** P1 骨架已落地：先 `npm run server -- 8080` 起权威模拟 server，再打开 `http://localhost:5173/?remote=ws://127.0.0.1:8080` 连入观察（可多人同时看同一个世界、下命令；进度以 server 为准，浏览器刷新不丢）。单机模式仍然完整可用。
- **LLM 在哪？** 预留了接口，当前版本是纯确定性（无 AI 对话/生成）。
