# infcanvas · 当前版本玩法说明（v0.1 · 单机 P0）

> 面向玩家的一页纸。想了解设计理念/架构看 `docs/DESIGN.md`，这里是**怎么玩**。

## 这是什么

一个会自动运转的殖民地模拟：一群小人会**自己**伐木、采矿、建造、祈祷、聊天、打架。
你主要是个**观察者 + 神谕**——偶尔下场帮一把、或者只管看戏。

## 开局你就该看到

- 屏幕中央 4 个小鼠人在**自动活动**（砍树/采矿/闲逛），下方篝火是你们的**部落营地**。
- 顶部资源条：🌲木头 · 🪨矿 · 🍖食物 · 🛠️工具 · 👥人数 · ☀️/🌙昼夜 · 天气。
- 小人会自动扩张营地：缺粮建农田、缺工具建工作台、没矿建矿洞、信仰高了建教堂。
- 如果开局是**空世界/一个人都没有** → 是旧存档坏了，刷新页面会自动重开一局。

## 关键玩法点

### 小人是自主的，别急着指挥
他们靠"抽卡"自决（3 选 1 择优），会疲劳、会饿、会闹脾气、会违抗安排。
你选中一个小人，面板会显示他刚才"闪念"了什么、为什么这么选。

### 指派职业（分工）
选中小人 → 面板点 **伐木工/矿工/农民/工匠**，他就专心干那行（生产线雏形）。
想恢复自由，点"自由"。

### 派系与战争（篝火 = 独立势力）
- **每个篝火 = 一个独立派系**，有自己的名字、部落记忆、对邻居的看法。
- 派系间会自动：**贸易**（友好时）、**传话**（关系一般时）、**袭击/吞并**（敌对时）。
- 点底部"🌍 派系"面板看全世界的势力网络；选篝火建筑可看它的记忆和看法。

### 教堂与神谕
- 信仰足够高时，AI 会**自动建教堂**（2x2，紫色）。
- 选中教堂 → 点"✨ 发布神谕" → 祝福附近的高信仰小人（30 秒心情加成）。
- 你**不能直接指挥**，只能通过神谕影响高信仰者——这是"神谕不碰选择链"的设定。

### 生存压力
- 野狼会**周期性袭击**！受伤要及时到篝火边疗伤；建墙保护营地。
- 食物会耗尽 → 尽早建农田；矿/木头要持续采。
- 小人会饿死/战死；若**全部团灭**，神谕会自动**附身**到其他存活派系继续。

### 突发事件
游戏会不定期冒出事件（流浪者加入、丰收、矿脉、瘟疫、游商、庆典……），
这些事件只会出现在**符合当前状况**时（有余粮才有流浪者、有农田才丰收）。

## 常见疑问

- **为什么小人不动？** 确认没暂停（看左下角是否 ⏸）；空世界请刷新重开。
- **怎么重开新局？** 目前自动存档每 30 秒写入浏览器；清空站点数据可重开。
- **能联机吗？** P1 骨架已落地：先 `npm run server -- 8080` 起权威模拟 server，再打开 `http://localhost:5173/?remote=ws://127.0.0.1:8080` 连入观察（可多人同时看同一个世界、下命令；进度以 server 为准，浏览器刷新不丢）。单机模式仍然完整可用。
- **LLM 在哪？** 预留了接口，当前版本是纯确定性（无 AI 对话/生成）。

## 兴趣（v0.1.1 · 2026-08-13）

- 每个小人天生有 **1-3 个兴趣**（采集/采矿/钓鱼/建造/祈祷/漫游/休憩）——决定 TA **娱乐时做什么**。
- 娱乐不再是清一色"闲逛"：爱采集的去采集、爱钓鱼的去钓鱼、爱建造的会琢磨营地里建点什么。
- 只有**对建造感兴趣**的小人会在娱乐时"灵光一现"规划新科技建筑（水井/木屋/竹筏…）——不感兴趣的人不会主动建。

## 玩家角色（v0.1.2 · 2026-08-13）

- **玩家不在模拟里**：小人和派系是完全自主的，玩家不是任何单位的一员。
- 你只通过两种方式影响世界：
  1. **指令**：选中小人下达移动/建造/指派（玩家命令路径，命令冷却后小人回归自主）。
  2. **神谕卡片**：神谕定时降旨（目标方向）/抽到策略卡时指示方向——神谕只引导目标层，小人仍自主抽卡择优，可能违抗。
- 顶栏的资源（🌲🪨🍖）是**全局仓库**——神谕眼中的世界总账。各派系另有自己的库存，用于贸易与自给。

## 篝火与派系（v0.1.3 · 2026-08-14）

- 每个小人有自己的**篝火归属**：在篝火周围生存，篝火记载这片区域发生过的事（建了什么、遭过袭击、谁战死了）。
- 只有**同区域（同 chunk）靠得够近**的小人才会互相**交流篝火的情况**——不是谁都聊得到。
- **伙伴还是敌人，看的是听到的历史**：听说你营地遭过袭击/成员战死 → 可能视你为敌；听说你建了新设施 → 可能视你为友。判断基于听到的事实，不是看数值。
- 营地**屡遭袭击会搬家**：小人在附近另起篝火另立门户（持续被侵扰才会走，偶尔一次袭击不会散伙）。
- 小人记得与其他小人之间的**个人关系**（谁帮过我、谁打过我），个体关系是真实的，派系是这些关系的浮现。

## 营地与迁徙（v0.1.3 · 2026-08-14）

- **营地被攻破才会搬家**：狼群路过营地不算"不舒适"，族人会战斗或躲藏；只有营地建筑真被拆了、还不断有威胁，才会另起篝火另立门户——而且新营地点会选在离老家远的地方。
- **归属随走动自然变化**：你在篝火旁生活就是那个营地的人；走到别的营地附近待久了，会自然成为那边的成员（不是生下来固定一个派系）。
- **营地被摧毁后**：族人四散成游牧，等新篝火建起再聚。

## 私人物品与互助（v0.1.3 · 2026-08-14）

- **自己采的食物装自己口袋**：捕鱼、矿洞捞到的食物进个人袋子；吃的时候先吃自己的，口袋空了才从公共粮仓拿。
- **好友会帮你**：和你关系亲近的人，看到你饿得快不行 / 受伤 / 情绪低落，会放下手头的活来帮你——分你食物、帮你包扎、陪你说话。前提是你俩够熟（好感够高）。
- **篝火记载大家的需求**：谁饿得发慌、谁情绪低落，会写进附近篝火的记忆里，别人听说了就会来帮忙。
- **帮助有回报**：被你帮过的人会记得你（好感提升），以后你有难处他也会帮你。

- 加载后没有农田/手作/科技/自主扩张——只有**采集 + 狩猎**：采木头、找吃的，然后**主动出击猎野猫**。

> 上文"派系与战争"（篝火 = 独立势力：贸易/袭击/吞并）、"各派系另有自己的库存，
> 用于贸易与自给"、"团灭后神谕附身其他派系"描述的是**已删除的旧机制**，以本节为准。

- **派系没有实体**：没有派系库存、没有派系间贸易/战争/吞并。篝火 = 营地势力只是
  **涌现展示**——每个篝火列出归属于自己的鼠鼠（按归属聚合），是观察视角，不是游戏对象。
- **团灭后不附身**：全部鼠鼠死亡后不会附身别的势力——世界重置（空世界自动重开一局）。
- 敌袭只有两类：**野猫袭击**（周期性，猫是鼠鼠天敌）与**鼠族掠夺者**（raider，保留的

  **玩法包**决定"这个世界还有什么"——默认 5 包全装（耕种/手作/修缮/科技/自主扩张），

  世界变成"采集 + 打猎"：没农田没工具没科技，靠采木头、捡吃的、主动猎野猫（猫掉肉进个人口袋）存活，
  营地被拆了鼠鼠会在原址重建篝火。

- 敌人头顶有**血条**（绿→橙→红按血量变色），选中的小人也显示血条 + 头顶**职业名**。
- 放大缩小时状态图标/血条/选中环**保持屏幕大小不变**（不会缩小成芝麻或占满格子）。
- 打开 📜 **历史面板**，带 📍 的行点击后**镜头直接跳转**到事发地点，面板自动收起。

## 科技碎片制（2026-08-14）

- 科技不再是"抽到整卡即解锁"，而是**碎片制**：每个科技由 **3 块碎片**组成，碎片攒齐才能组成科技（也是抽卡——碎片来自独立的科技抽卡池，神谕不降科技）。
- 科技抽卡池隔一段时间（默认 120 秒）有概率发一块碎片；**顺序靠前的科技更容易先攒齐**（"往后抽卡"渐进不变）。
- 攒碎片过程随时可见：科技面板（Y 键）显示未解锁科技 🔩 **碎片 x/3** 进度；拾获碎片会在历史记录里显示「🔩 拾获 ××碎片（x/3）」。
- 攒满 3 块 → 「🔬 科技完成」，自动解锁该科技全部内容（可建造对应建筑）。
- 进度**随存档保留**：攒一半的科技读档继续攒。

## 采集狩猎玩法（mod，2026-08-14）

- `hunter-gatherer` 玩法包卸载了耕种/手作/科技/自主扩张/维修/**医疗**：纯采集 + 狩猎的游牧生活。
- **白天狩猎**：野猫在营地外围（15-40 格）游荡，猎人主动索敌追猎，击杀掉**肉×4 进个人口袋**（私有，不进公共粮仓）。
- **夜晚回营**：天黑后在外工作的人会**自动回篝火旁夜宿**（夜归卡），不会野外过夜。
- **营火自治**：营地被拆会自动重建；人口增长会自动**补篝火**（约 1 火/4 人）保证火边夜宿。
- **理智**：游牧民族耐受野外夜宿（夜流失很低）、伤势不扰心智（无医疗伤口层）；崩溃者会本能逃向最近篝火，在火旁呆着慢慢恢复。

## 建造反馈与伤口上限（2026-08-14 第二轮试玩）

- **建造指令被拒时有明确提示**：📛 建造被拒：位置被占用 / 建筑不存在 / 科技未解锁 / 木材或矿石不足——不会再"点了没反应"。
- **伤势不会无限叠加**：淤伤最多 3 条、流血最多 3 条、感染最多 1 条——满身伤不治拖成大病，但不会叠几十条伤口让理智永远无法恢复（火旁养伤必定回得来）。

## 受伤与养伤（RimWorld 规则，2026-08-14 重构）

- **伤口会自然愈合**：不治疗也会随时间好转——切割伤约 1 分钟、淤伤 1 分半、烧伤 2 分钟自动痊愈；伤势不会越攒越多。
- **伤口分部位**：四肢/躯干/头部——命中概率四肢最高、头部最低；**头部伤最重**（流血更快、更疼）。
- **流血会失血**：新伤（切割/咬伤）会流血，掉血 + 心慌掉理智；小伤口自己会凝血，大伤口需要处理，**一直流血不处理会失血而死**。
- **伤口会感染**：没处理的伤口有小概率感染（头部伤口更易感染）——发烧、持续掉血、心慌；拖到恶化（坏疽）很危险，需要尽快治疗。
- **治疗 = 包扎处理**：走到篝火旁养伤，处理伤口能止血、退烧、加速愈合；**感染的伤口会优先被处理**。
- **疼痛随愈合消退**：新伤最难受，伤快好了就不疼了。

## 地道（2026-08-14）

- **可以挖地道**：下达建造指令选「地道」，在水边、山脚甚至草地上都能挖（水下通道/穿山隧道/地窖入口），成本便宜（木头 4 根），不用科技。
- **地道 = 地下捷径**：走进地道能从水下/山体里穿过去，不用绕河绕山；**但地道里走得和普通地面一样快**（速度没有加成，快在路线直、不在地快）。
- **地道是窄道**：一格宽，里面只能过人——**不能把篝火、仓库、床等任何建筑盖进地道里**，大宗物资不经过地道（想运输还得走陆路）。

## 地道与道路（2026-08-14 维度化重设计）

- **地道 = 地下世界（另一维度）**：地表上看不到地道（不在地形上显示）——它不在地图上，地图上是看不到的；入口挖在能站人的地面上（草地/泥地/沙地/石头），**任意两个入口之间地下直连**——走进一个入口，从另一个入口出来，中间穿过的地表（河/山/坡）一概不影响（地下隧道在地表之下）。
- **地道里没有速度加成**：快在路线直（入口间直线通行），不在地道里走得快。
- **地道入口是窄口**：一格宽，入口格上不能盖任何建筑。
- **可以修道路**：道路铺在地表上、看得见——草地/泥地/沙地/石头都能修。道路是坡道：**陡坡（高差大的地形）修上路就能上下**，不修路爬不上去。
- **地形有高低（z 值）**：石头比草地高一格、山地最高——**高差超过你的攀爬能力就上不去**；鼠人攀爬能力有限（只能上一格高差），**野猫比鼠人更能爬**（能追上山坡）。上不去的地方：修路（垫平）或绕行。

## 高低差地图（2026-08-14）

- **地图有高地了**：石头是高出一大截的**石丘**（比草地高 2 层）——石丘边上就是**绝壁**，鼠人爬不上去（攀爬能力只够上一层）。
- **野猫能爬上石丘**：猫的攀爬能力更强，能上石丘追你——石丘不是安全区。
- **翻越石丘的办法**：**修路**（把路铺上石丘 = 垫坡道）或**挖地道**（入口间地下直穿）。
- 地图上的山丘带：低地 → 石头缓坡 → 石丘高地，探索时会遇到需要修路/绕行的高地。

## 无限地图（2026-08-14）

- **世界是无限的**：往任意方向探索都能走出出生区，地形按坐标确定性地生成（同一次存档里同一位置永远是同一片地形）。
- **探索过的地方才记得**：你建造/改造过的地方（覆盖层）会存进存档，纯野生的地形是"算出来的"，不占存档。
- **镜头会跟着你**：地图按区域（chunk）按需加载，走到哪渲染到哪，远处和身后没看的地方不占内存。
- **可以走负坐标**：往出生区左/上走就是负坐标，照常建营地、挖地道、修路（存档里也存得下）。

## 篝火烹饪 + 夜晚保温（2026-08-14）

- **篝火会做饭**：营火会自动把杂食烤成耐存的熟食——每轮消耗 **4 食物 + 1 木**、烤出 **5 食物**（约 4 秒一轮，营火越多轮流越快）。缺粮/缺柴时不动锅（不会把仅有的口粮烧掉）。历史日志能看到「🍳 烤制食物完成」。
- **夜里火旁保持温暖**：夜晚（或雨天夜里）环境温度往下掉，但只要站在篝火/暖炉的热源覆盖区内，温度就**保持**在 15°C 不沉——火堆是夜里取暖的地方；野外没有火堆的地方该冷还是冷。
- 烹饪是篝火自带的能力（不依赖工作台科技），卸载了加工玩法（采集狩猎局）的营火也照样能烤肉。

## 香料（2026-08-14）

- **野外长香料丛**：草地上低概率长着 **🌿 香料丛**（灌木，能直接走过去，不像树挡路）。采它跟采树一样（收获 1~2 株香料），采完变草地。
- **香料让篝火烤得更划算**：篝火烹饪时只要库存里有香料，就会自动改烤"香料烤制"——**4 食物 + 1 木 + 1 香料 → 7 食物**（比不加料多出 2 份）。香料用完自动回落成普通烤制，不会停火。
- 香丛有限（约 0.5% 草地密度）、香料是野外资源——出门采香料、回来加料烤，是营地食物的进阶玩法。

## 工作优先级（Work Tab，RW-1 M1，2026-08-15）

- **⚙ 工作面板**：点按钮区「⚙ 工作」打开——像 RimWorld Work Tab 一样，**每行 = 一项工作（采集/建造/耕种/手工/修缮/医疗/火力/贸易/囚笼/烹饪/制衣…），每列 = 一个小人**。格子状态：空白 = 全自动（听抽卡）、**0 = 禁止做这项**、**1~4 = 优先级（1 最高，4 最低）**。
- **点选循环**：点一个格子按 空白 → 1 → 2 → 3 → 4 → 0 → 空白 循环。
- **效果**：优先级高的工作更可能被抽到；标 0 的工作一定不会自动去做。紧急需求（饿极了/困极了）仍然优先，不会被优先级压住。
- **旧指派兼容**：「指派职业」按钮语义 = **快捷设定**——指派主职后，该主职优先级强制 1、其他全部 0（其余人照旧）；取消指派 = 全部回到自动。老存档升级后自动按这个规则迁移，已有微调不受影响。
- **选中面板摘要**：选中小人时显示「优先级 → 工作名」各行；有禁止项显示**红色「禁止」**；全自动显示「全自动」。

## 征召战斗（RW-1 M2，2026-08-15）

- **⚔ 征召**：选中鼠鼠 → 信息面板点「⚔ 征召」。被征召的小人**停止一切自主行为**（不干活/不吃饭/不睡觉/不治疗/不休闲），原地待命听你指挥；**被动消耗照旧**（饿了/困了照样会累积——征召不是免死金牌，要及时解除）。
- **被征召的标识**：小人头顶有**金色圈环**（任意缩放大小不变，一眼认出征召队）。
- **右键攻击**：选中**已征召**的小人，右键敌人 → 小人自动跑到敌人身边交战（伤害/闪避/掉落沿用战斗规则）。带指定目标时优先打指定目标，没有指定就自动打范围内最近的敌人。
- **手动移动**：征召中小人仍听移动命令（右键空地走过去）。
- **☮ 解除征召**：再点一次「☮ 解除征召」恢复自主——会立刻接着按需求/工作自主行动。已指定的攻击目标自动清除。
- **小提示**：敌人来袭时先征召 2-3 个小人组成战斗小队，其余人继续生产；战斗结束第一时间解除征召让伤员去治伤（征召小人不会自己治伤！）。
