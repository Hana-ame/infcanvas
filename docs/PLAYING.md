# infcanvas · 当前版本玩法说明（v0.1 · 单机 P0）

> 面向玩家的一页纸。想了解设计理念/架构看 `docs/DESIGN.md`，这里是**怎么玩**。

## 这是什么

一个会自动运转的殖民地模拟：一群小人会**自己**伐木、采矿、建造、祈祷、聊天、打架。
你主要是个**观察者 + 神谕**——偶尔下场帮一把、或者只管看戏。

## 开局你就该看到

- 屏幕中央 4 个小鼠人在**自动活动**（砍树/采矿/闲逛），下方篝火是你们的**部落营地**。
- 顶部资源条：🌲木头 · 🪨矿 · 🍖食物 · 🛠️工具 · 👥人数 · ☀️/🌙昼夜 · 天气。
- 小人会自动扩张营地：缺粮建农田、缺工具建工作台、没矿建矿洞、信仰高了建教堂。
- 如果开局是**空世界/一个人都没有** → 是旧存档坏了，刷新页面会自动重开一局。

## 基本操作

| 操作 | 做法 |

| 选中小人 | 鼠标左键点击小人（看属性/指派职业） |

## 关键玩法点

### 小人是自主的，别急着指挥
他们靠"抽卡"自决（3 选 1 择优），会疲劳、会饿、会闹脾气、会违抗安排。
你选中一个小人，面板会显示他刚才"闪念"了什么、为什么这么选。

### 指派职业（分工）
选中小人 → 面板点 **伐木工/矿工/农民/工匠**，他就专心干那行（生产线雏形）。
想恢复自由，点"自由"。

### 派系与战争（篝火 = 独立势力）
- **每个篝火 = 一个独立派系**，有自己的名字、部落记忆、对邻居的看法。
- 派系间会自动：**贸易**（友好时）、**传话**（关系一般时）、**袭击/吞并**（敌对时）。
- 点底部"🌍 派系"面板看全世界的势力网络；选篝火建筑可看它的记忆和看法。

### 教堂与神谕
- 信仰足够高时，AI 会**自动建教堂**（2x2，紫色）。
- 选中教堂 → 点"✨ 发布神谕" → 祝福附近的高信仰小人（30 秒心情加成）。
- 你**不能直接指挥**，只能通过神谕影响高信仰者——这是"神谕不碰选择链"的设定。

### 生存压力
- 野狼会**周期性袭击**！受伤要及时到篝火边疗伤；建墙保护营地。
- 食物会耗尽 → 尽早建农田；矿/木头要持续采。
- 小人会饿死/战死；若**全部团灭**，神谕会自动**附身**到其他存活派系继续。

### 突发事件
游戏会不定期冒出事件（流浪者加入、丰收、矿脉、瘟疫、游商、庆典……），
这些事件只会出现在**符合当前状况**时（有余粮才有流浪者、有农田才丰收）。

## 当前版本已实现的完整清单

## 常见疑问

- **为什么小人不动？** 确认没暂停（看左下角是否 ⏸）；空世界请刷新重开。
- **怎么重开新局？** 目前自动存档每 30 秒写入浏览器；清空站点数据可重开。
- **能联机吗？** P1 骨架已落地：先 `npm run server -- 8080` 起权威模拟 server，再打开 `http://localhost:5173/?remote=ws://127.0.0.1:8080` 连入观察（可多人同时看同一个世界、下命令；进度以 server 为准，浏览器刷新不丢）。单机模式仍然完整可用。
- **LLM 在哪？** 预留了接口，当前版本是纯确定性（无 AI 对话/生成）。

## 兴趣（v0.1.1 · 2026-08-13）

- 每个小人天生有 **1-3 个兴趣**（采集/采矿/钓鱼/建造/祈祷/漫游/休憩）——决定 TA **娱乐时做什么**。
- 娱乐不再是清一色"闲逛"：爱采集的去采集、爱钓鱼的去钓鱼、爱建造的会琢磨营地里建点什么。
- 只有**对建造感兴趣**的小人会在娱乐时"灵光一现"规划新科技建筑（水井/木屋/竹筏…）——不感兴趣的人不会主动建。

## 玩家角色（v0.1.2 · 2026-08-13）

- **玩家不在模拟里**：小人和派系是完全自主的，玩家不是任何单位的一员。
- 你只通过两种方式影响世界：
  1. **指令**：选中小人下达移动/建造/指派（玩家命令路径，命令冷却后小人回归自主）。
  2. **神谕卡片**：神谕定时降旨（目标方向）/抽到策略卡时指示方向——神谕只引导目标层，小人仍自主抽卡择优，可能违抗。
- 顶栏的资源（🌲🪨🍖）是**全局仓库**——神谕眼中的世界总账。各派系另有自己的库存，用于贸易与自给。

## 篝火与派系（v0.1.3 · 2026-08-14）

- 每个小人有自己的**篝火归属**：在篝火周围生存，篝火记载这片区域发生过的事（建了什么、遭过袭击、谁战死了）。
- 只有**同区域（同 chunk）靠得够近**的小人才会互相**交流篝火的情况**——不是谁都聊得到。
- **伙伴还是敌人，看的是听到的历史**：听说你营地遭过袭击/成员战死 → 可能视你为敌；听说你建了新设施 → 可能视你为友。判断基于听到的事实，不是看数值。
- 营地**屡遭袭击会搬家**：小人在附近另起篝火另立门户（持续被侵扰才会走，偶尔一次袭击不会散伙）。
- 小人记得与其他小人之间的**个人关系**（谁帮过我、谁打过我），个体关系是真实的，派系是这些关系的浮现。

## 营地与迁徙（v0.1.3 · 2026-08-14）

- **营地被攻破才会搬家**：狼群路过营地不算"不舒适"，族人会战斗或躲藏；只有营地建筑真被拆了、还不断有威胁，才会另起篝火另立门户——而且新营地点会选在离老家远的地方。
- **归属随走动自然变化**：你在篝火旁生活就是那个营地的人；走到别的营地附近待久了，会自然成为那边的成员（不是生下来固定一个派系）。
- **营地被摧毁后**：族人四散成游牧，等新篝火建起再聚。

## 私人物品与互助（v0.1.3 · 2026-08-14）

- **自己采的食物装自己口袋**：捕鱼、矿洞捞到的食物进个人袋子；吃的时候先吃自己的，口袋空了才从公共粮仓拿。
- **好友会帮你**：和你关系亲近的人，看到你饿得快不行 / 受伤 / 情绪低落，会放下手头的活来帮你——分你食物、帮你包扎、陪你说话。前提是你俩够熟（好感够高）。
- **篝火记载大家的需求**：谁饿得发慌、谁情绪低落，会写进附近篝火的记忆里，别人听说了就会来帮忙。
- **帮助有回报**：被你帮过的人会记得你（好感提升），以后你有难处他也会帮你。

### 世界观修正（2026-08-14）
- 本作小人是**鼠鼠**，天敌是**野猫**（不是狼——早期实现的"野狼"是设定错误，已全部替换为野猫）。
- 旧文档上文中的"野狼"均指野猫（历史记录保留原文，此处更正）。

## 采集狩猎玩法包（mod，2026-08-14）

- 加载后没有农田/手作/科技/自主扩张——只有**采集 + 狩猎**：采木头、找吃的，然后**主动出击猎野猫**。
- 野猫会掉**肉**（进你个人口袋），吃饱了靠采集和打猎。
- 野猫会周期性袭击营地，营地被拆了鼠鼠们会**在原址重建篝火**。
- 加载方式：`new Sim({ mods: hunterGatherer })` 或 `?mods=.../hunter-gatherer.ts`。

## 更正：派系实体层已删（v0.2 · 2026-08-14）

> 上文"派系与战争"（篝火 = 独立势力：贸易/袭击/吞并）、"各派系另有自己的库存，
> 用于贸易与自给"、"团灭后神谕附身其他派系"描述的是**已删除的旧机制**，以本节为准。

- **派系没有实体**：没有派系库存、没有派系间贸易/战争/吞并。篝火 = 营地势力只是
  **涌现展示**——每个篝火列出归属于自己的鼠鼠（按归属聚合），是观察视角，不是游戏对象。
- **团灭后不附身**：全部鼠鼠死亡后不会附身别的势力——世界重置（空世界自动重开一局）。
- 敌袭只有两类：**野猫袭击**（周期性，猫是鼠鼠天敌）与**鼠族掠夺者**（raider，保留的
  鼠族内部冲突，掠夺者定义在敌人表，可被 mod 修改/移除）。

## 玩法包化（v0.2 · 2026-08-14）

- 模拟器 = **内核 + 玩法包叠加**：内核永远有需求/理智/欲望/行为/社交/采集/建造/敌袭/人口/事件；
  **玩法包**决定"这个世界还有什么"——默认 5 包全装（耕种/手作/修缮/科技/自主扩张），
  体验与之前完全一致。
- 换玩法 = 换包：`?mods=.../hunter-gatherer.ts` 加载**采集狩猎包** → 卸掉耕种/手作/科技/自主扩张，
  世界变成"采集 + 打猎"：没农田没工具没科技，靠采木头、捡吃的、主动猎野猫（猫掉肉进个人口袋）存活，
  营地被拆了鼠鼠会在原址重建篝火。
- 未来新玩法（新包/新系统/新卡/新建筑）都会以 mod 形式提供，玩家自由组合。
## 状态图标与反馈（v0.1.3 · 2026-08-14）

- 小人头顶会显示**最紧急状态**图标：受伤(❤️🩹) > 狂乱(😵) > 饿(🍗) > 困(😴)，一眼看到该救谁。
- 选中小人脚下有**黄色圆环**跟随；右键移动会从小人画一条**方向箭头**到目标点，落地处有圆环标记（1.2s 淡出）。
- 排队建造的蓝图格底部有**蓝色进度条**，实时显示建造进度。
