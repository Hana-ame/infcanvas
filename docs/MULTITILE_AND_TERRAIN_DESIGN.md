# InfCanvas · RimWorld 多格建筑系统、地形系统与可折叠 UI 设计说明

## 1. 多格系统（Multi-Tile Footprint & Rotation）设计逻辑

### 1.1 多格占地尺寸与 90° 旋转朝向 (`rot: 0 | 1 | 2 | 3`)
- **占地模型 (`w × h`)**：
  - `1×1` 单格构筑：木石围墙 (`wall`，支持 N/E/S/W 四向自动连通拼接)、自动门 (`door`)、营地篝火 (`campfire`)、迷你机枪塔 (`turret`)、尖刺陷阱 (`trap`)、战术空投信标 (`raid_beacon`)。
  - `2×1` / `1×2` 非对称多格设施：燃木炉灶 (`stove`, 默认 `2×1`)、基础研究台 (`research_bench`, 默认 `2×1`)、医疗病榻 (`bed`, 默认 `1×2`)。
  - `2×2` 正方形多格建筑与区域：殖民者木屋 (`hut`)、物资仓库 (`store`)、肥沃农田 (`field`)、防卫哨塔 (`tower`)、基因组装舱 (`gene_assembler`)、黄金鼠王宝座 (`royal_throne`)、丰饶橡果祭坛 (`ideology_altar`)、人格核心主脑 (`ai_persona_core`)、野生乔木 (`tree`)。
  - `5×5` 复合多格城防据点：野生 NPC 友好集市与敌对海盗要塞 (`WildNpcBase`，含四角炮塔墩、外圈城墙、中央 `2×2` 主堡与阵营旗帜)。
- **朝向旋转 (`rot`)**：
  - 在建造规划模式下按快捷键 `R`（或点击顶栏「旋转朝向 (R)」/ 底部 Gizmo 栏「朝向」按钮），`rot` 按 `0 (0°) → 1 (90°) → 2 (180°) → 3 (270°)` 循环。
  - 当 `rot` 为奇数 (`1` 或 `3`) 时，建筑的有效占地宽高自动互换：`effectiveFootprint = { w: baseH, h: baseW }`（例如 `2×1` 的燃木炉灶旋转 90° 后变为 `1×2` 竖向炉灶）。

### 1.2 全子格精确命中 (`buildingAt`) 与周界交互 (`nearestBuildingAdjacent`)
- **全子格命中 (`World.buildingAt(x, y)`)**：
  - 阻挡型多格建筑写入 `occupied` 哈希表实现 $O(1)$ 查询；
  - 可通行多格建筑（如 `2×2` 农田、`2×2` 哨塔、`1×2` 医疗病榻）按完整闭区间矩形 `[b.pos.x, b.pos.x + w - 1] × [b.pos.y, b.pos.y + h - 1]` 判定，确保鼠标点击、悬停检视或拆除多格建筑的**任意一个子格**都能 100% 命中该建筑。
- **逐格蓝图校验 (`inspectFootprintCells`)**：
  - 在落子前对 `w × h` 范围内的每一个子格 `(x + dx, y + dy)` 独立校验地形可通行性、跨格海拔平整度 ($\Delta z = 0$)、地基承载力、农田肥力门槛及已有建筑冲突，并在 Canvas 上实时绘制逐格绿 (`#4cd964`) / 红 (`#ff4d4d`) 蓝图预览框。

## 3. 纯图形化渲染、AI 驱动推后 DLC 与全可折叠菜单体系

1. **100% 纯图形化渲染与缩放对齐**：
   - 彻底移除 Canvas 上的文字与 Emoji 占位符，所有单格/多格建筑、四向连通墙体、`2×2` 乔木、浆果丛、矿脉、`5×5` 据点与鼠鼠殖民者均由 `Graphics` 矢量精灵绘制。
   - 滚轮缩放时实时调用 `renderCache.setTilePx(TILE)` 重新烘焙可见地形块，配合 `toWorld` 的 `-0.5` 格心校准，确保任意缩放倍率下地形、网格、多格建筑与单位 100% 像素对齐。
2. **AI 驱动功能收纳至独立 DLC（推后实现）**：
   - 新增官方扩展包 #5 `dlc-ai-director`（**AI Director · 自治叙事者与 AI 驱动扩展包 [⏳ 推后实现 / Deferred]**），本体默认聚焦玩家手动工作优先级、直接征召微操与玩家扮演 Raid。
3. **全界面菜单支持折叠 (`各个菜单需要能够折叠`)**：
   - 顶部殖民者肖像栏 (`▾ 殖民者栏`)
   - 左上物资树总面板 (`▾ 殖民地物资清单`) 及内部 4 大分类 (`▾ 食物储备` / `▾ 原木与石材` / `▾ 矿物与金属` / `▾ 医药与零件`)
   - 左下角检视窗 (`▾ 检视窗`)
   - 底部中央战术指令栏 (`▾ 战术指令`)
   - 右上角警报与信封栈 (`▾ 警报与信封`)
   - 右下角地形与时间读数面板 (`▾`)
   - 底部弹出式主抽屉 (`▾ 折叠面板` 按钮或再次点击底部标签)
