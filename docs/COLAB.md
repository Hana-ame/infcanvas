## 关于"游戏制作目的"的问题清单（user 已全部回答）

**用户答案摘要**：
- **Q1 乐趣支柱**：所有。核心 = 模拟器，观察所有 pawn 自行建造/开拓/战争；player 也可下场达成想要结果。
- **Q2 饥荒 vs 神谕**：共存。小人发展后可自建教堂；神谕 player 可直接下场影响高信仰小人。
- **Q3 失败**：纯观察 sim；团灭可附身其他教堂/小人；目标含搭建奇观/工作流（天际线式）。
- **Q4 验收**：确定性 AI + 确定性抽卡 + 框架合理 + 能加 MOD。
- **Q5 无 LLM 灵魂**：在。保留后期 LLM 插入框架能力；现在用随机事件 + 预制剧本。
- **Q6 神学主题**：不需特殊化。信仰 = 抽卡行为的一组卡池，不必特意区分。
- **Q7 暂停**：最终联机时会去掉；现在随意。
- **Q8 最小成**：自动控制的 RimWorld 感；**工作优先指令由 AI（LLM or non-LLM）下达，随环境转变**；**小人之间需有社会关系以支持协作/战争**。

### Q1 玩家的乐趣支柱到底是什么？
北极星写"模拟现实社会"，一切机制为"社会真实运转"服务（DESIGN §0/§1）。
但玩家坐在屏幕前玩的时候，**他的乐趣来源**是：
A) 看"狗屁倒灶"的喜剧效果（观测者/吃瓜乐趣）
B) 神谕 vs 小人意图失真的"斗智斗勇"（博弈乐趣）
C) 培养/编程小人，凹出理想配置（养成乐趣）
D) 其它
这直接决定所有系统的优先级排序，现在文档没说清主次。

A: 所有. 主要是模拟器,观察在本系统下所有pawn的行为,他们会自己建造,自己开拓,自己战争.player也会下场得到想要的结果.

你口头说"可以当成饥荒玩"，但 DESIGN 明确"玩家不逐个指挥小人"、"玩家不是遥控器"（§1/§3）。
饥荒/RimWorld 是直接操纵，神谕是间接影响。P0 阶段玩家到底：
- 手动指挥殖民地（饥荒式），还是
- 只施加神谕影响（DESIGN 式）？
还是两者共存？若共存，边界在哪？

A: 这之前应该写入过文档,写的是小人发展之后可以自己创建教堂,神谕player也可以直接下场影响高信仰值的小人.

饥荒/RimWorld 的紧张感来自生存压力。P0 要不要有失败/团灭作为压力源？
还是纯观察、无任何惩罚？

A: sim, 看发展, 团灭可以直接附身其他的教堂/小人. 可能是搭建奇观,或者是异星工厂那样的,搭建工作流.(天际线咋玩的?可能有点像)

### Q4 P0 做完要验证什么（验收标准）？
P0 这一版做出来后，你希望确认的是：
A) 确定性 AI 能让小人自己活下去（自主行为成立）
B) 抽卡系统 + 意图失真本身有趣
C) 游戏好玩、值得继续投入
D) 基础设施（ECS/寻路/地形/存档）可扩展，后面能往上加东西
不同答案 → P0 的打磨重点完全不同。

A: 确定性AI, 确定性抽卡系统, 游戏框架合理, 能加MOD

### Q5 没有 LLM 的 P0，灵魂还在吗？
DESIGN 里 LLM 贯穿始终（神谕、对话、事件、野生神谕），但 P0 明确"纯确定性、无 LLM"。
缺了 LLM，靠卡系统 + 狗屁倒灶日志 + 袭击能不能撑起"这游戏有意思"？
还是 P0 就该把"神谕/教堂/信仰"的**确定性骨架**也做出来（预设指令+插槽，先不接 LLM）？

A: 在的, 请保留后期LLM能够插入框架的能力, 现在可以暂时用随机事件, 预制剧本.

### Q6 中世纪神学主题现在要不要体现？
七宗罪/教堂/神谕的主题很重（§3 欲望系统、信仰），但当前 P0 生态是荒野生存（狼群、砍树、矿洞、篝火）。
P0 需不需要现在就做出"信仰"闭环（祈祷→心情/信仰/违抗概率）？
还是主题系统等 P1.5 再整体上？

A: 不需要, 信仰只是抽卡行为的一种, 相当于一组卡池, 不必特别作出区别

### Q7 暂停/倍速哪个为准？
