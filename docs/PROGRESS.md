## 技术栈

- Vite + TypeScript + PixiJS v8 + bitecs ECS（SoA）+ vitest
- sim = 纯 TS 双端共用（`src/sim/` 零 DOM/PIXI），P1 起 server 直接 import
- 确定性：SimRng（种子化）+ 固定系统顺序 + 独立 world chunk 生成
