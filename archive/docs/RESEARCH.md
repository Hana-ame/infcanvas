# 竞品玩法研究报告

> 2026-08-03 · 为 infcanvas 设计提供参考
> 范围：上帝模拟 / 自主文明 / 自主派系沙盒 / LLM 驱动游戏 四类竞品的玩法与实现机制

## 1. 上帝模拟类（玩家=神，文明自主）

### WorldBox
- 玩家拥有大量神力工具（闪电/陨石/祝福/诅咒），**无需资源/冷却**——靠工具粒度粗 + 事件离散约束
- 玩家**无法直接建造村庄**（只能靠人口过密促成分村）、无法控制任何小人；城镇/王国/战争/贸易全由确定性 AI 自己长出来
- 内部动力学：国王/领主属性影响忠诚度，低忠诚引发**叛乱分裂**；文化可脱离王国存续；时代系统（Hope/Despair/Ash）带来全局压力
- 全知：全图上帝视角。教训：全知 + 无约束会让干预变成遥控器

### Black & White（黑与白）
- 核心货币 = **信仰（Prayer Power）**：村民祈祷/献祭产生信仰，信仰决定影响圈（Influence Ring）大小——**神手越过影响圈就无法干涉**
- 重复同一神迹**收益递减直至归零**；村民完全自主（职业/繁殖/社会运转）
- 神唯一的化身是**巨兽**：神经网络+行为树学习神的示范，且**会学歪**（误学是设计特性）
- 邪恶路线见效快但摧毁村庄结构；村庄需求随事件变化

### Populous
- 干预几乎全部是**地形塑形** + 四种行为模式指令（定居/集结/先战后定居）；"铺平地→小人建房→人口→法力"是涌现循环
- **信徒数 = 法力再生速度**；续作引入战争迷雾

### Reus
- 神（巨人）的权柄止于"环境供给"：塑造地形/资源分布，**人类的意志完全不可控**
- 资源**过度富足 → 人类变贪婪 → 村庄开战**（善意反噬内嵌进经济系统）

### Godus（反面教材）
- 失败原因：承诺崩坏、手游化内购骗局、玩法空洞（只是 Populous 模板重写）、**神被降格成做苦工的劳动者**
- 教训："神"的体验必须来自有意义的间接杠杆 + 可见的因果涟漪，绝不让神做琐碎工作

## 2. 自主文明类

### Dwarf Fortress
- 矮人半自主：玩家下 designation，空闲矮人自动认领 job；**个人需求 job 可打断要塞 job**（高优先级"向神祈祷！"不可取消）
- 性格（500+ 交互需求/性格/关系/记忆）+ 短时记忆（8 条，可固化成长时记忆，创伤性记忆持久影响）
- **无玩家时世界照常**：世界生成 = 零玩家策略游戏 + 仿真日志（模拟千年历史）；玩法阶段历史继续推进
- **Legends**：事件/人物/地点全部结构化记录，可导出；玩家成就自动入档
- 世界生成全阶段 seed 确定性、可复现
- 最深点：物质→社会正反馈回路（脏医院→坏记忆→低可靠性→更糟的医院）
- 结论：复杂可信行为可由刚性规则涌现，LLM 只是事后合理化

### Songs of Syx
- 数万市民**每个都是独立个体**：名字/需求/欲望/家族谱系/宗教/恐惧；幸福度按个体聚合，群体不满→暴动/出走/叛变
- 世界地图其他王国自主扩张/联盟/贸易/战争，**与玩家是否干预无关**
- 移民 = 可拒绝的个体而非抽象数字（幸福度>80% 才产生移民，人口增长是"社会吸引"）
- 最深点：**死亡螺旋**（单一资源短缺→不满连锁→抢劫→全城崩溃）是涌现而非脚本

### Caves of Qud
- **历史生成**：苏丹生平事件由"阶段化模板 + 约束满足"生成——确保历史一致性、**每个历史区域至少被提及一次**
- 事件之间互相约束（婚姻获得的遗物可在后来战役中失去）；史书用马尔可夫链生成文风
- 历史不只生成文字：生成政府/村庄/宗教/派系，产生历史遗迹供探索；玩家通过探索逐步揭开被偏见包裹的真实历史
- NPC 与玩家完全对称；回合制、世界运行时不演化（生成时完整而非运行时持续）

### Ultima Ratio Regum
- 纯探索无战斗；**意义链（chains of meaning）**：万物不孤立生成——植被→疗法→宗教象征→方言→家族纹章
- 文化属性互相制约（政教合一社会不会生成宗教自由）；**与既有文化太相似就重掷**，刻意制造差异
- 250 万格世界，18 座城市；静态世界，无运行时演化

### Kenshi
- NPC 有真实状态（饥饿/疲劳/伤口/装备）；农民种地、守卫巡逻是持续运行的 AI routine（非动画演出）；断臂 NPC 装义肢继续活
- "You are not the centre of the universe"；无等级缩放；玩家死了世界照常
- **世界状态系统**：条件→覆盖状态（杀死领袖→城镇易主→新派系入侵）；后果持久、完全不通知玩家
- 诚实说明：地图固定非无限；vanilla 派系间**不互相开战**（需 mod）

## 3. 自主派系沙盒类

### X4: Foundations
- **自下而上全模拟经济**：数百空间站/数千船只真实采掘加工贸易，价格供需实时决定，飞船武器都由经济生产（不凭空刷）
- 派系按供需缺口自主扩建空间站；玩家是"补缺者"（vanilla 派系经济被故意设计成残缺）
- 声誉系统（-30~+30，对数曲线）+ 8.0 外交系统；玩家从单船小角色成长为帝国

### Starsector（远行星号）
- "太空版骑砍"：玩家只是舰队指挥官；每个殖民地实时模拟经济（公开市场+黑市，30% 关税）
- 派系**自动宣战**（6 个月到 1 年周期）与玩家无关；世界有自己的历史恩怨
- 间接影响：声誉、佣金制（当雇佣兵自动卷入战争）、扶持弱派——永远不是指挥官

### Mount & Blade（骑砍）
- 六大王国 AI **自动开战/议和/吞并**，与玩家是否干预无关（PC Gamer 原话）
- **NPC 领主与玩家遵守完全相同的规则**（补给/募兵/金钱），行为效用评估：距离/需求/兵力/领地邻近/宿怨
- **战争有经济逻辑**：劫掠村庄切断城堡补给线；围城先评估成功率

### Crusader Kings 3
- **玩家只控制一个角色**的成功范本：数十万角色构成自治社会
- NPC 自主形成友谊/仇怨/联盟/联姻网络，互相跑阴谋（刺杀/诱拐/夺权）
- 事件链从角色处境涌现而非围绕玩家；玩家角色死后由后代继承，世界历史是所有人共同书写
- **压力系统约束所有人（含玩家）**：违背性格行事付代价；玩家过强→周边王朝自发结盟制衡
- 启示：自主演化密码 = **统一角色模型 + 关系网络 + 低成本意图表达**，不是复杂 AI

### Dyson Sphere Program / Factorio（物流链）
- 核心循环：采集→运输→加工→组装→科研→扩规模→新瓶颈；物流有明确层级（本地→行星→星际）
- 乐趣来源：**瓶颈即谜题**、自动化自动化本身（后期玩家是设计师不是操作员）、**可视化的流动**、系统诚实性（出问题一定是规划失误，无随机惩罚）
- 启示：物流不是装饰而是**可读性工具**——让经济运转可见可诊断，瓶颈处就是干预点

## 4. LLM 驱动游戏类

### AI Roguelite
- LLM 裁决一切：地点/NPC/敌人/物品/配方实时生成；战斗 = 文本合理性 + **确定性骰子检定**
- 回合制把 LLM 延迟从实时压力变成体验节奏
- 商业模式验证：买断 + 推理订阅（免费云层→月费→自定义 API→本地 Ollama）

### AI Dungeon
- 上下文由五类组件拼装：AI 指令 / Plot Essentials / Author's Note（常驻）+ **Story Cards**（关键词触发注入）+ 最近剧情
- **Memory System**：每 6 个玩家行动压缩成一条记忆，embedding 排序相关性检索注入
- 动态路由（按查询复杂度切换模型）；教训：上下文遗忘直接毁掉"选择有意义"的承诺

### Inworld / Convai / NVIDIA ACE
- Inworld：character brain 运行时层（人格/情绪/记忆/行为目标）；前缀缓存省成本；回退链（本地缓存→行为树→预写内容）
- Convai：游戏内延迟常 10s+（玩家不可接受）
- NVIDIA ACE（2026）：转向 on-device SLM（RTX 4090 <100ms）
- 三大失败模式：**topic bleed**（知识越界）/ **memory horizon collapse**（上下文重置即失忆）/ **latency spike**
- 语义缓存可削减 70%+ API 成本

### Generative Agents（Smallville，Park et al. 2023）
- 25 个 agent：**记忆流**（时间戳 + LLM 赋重要性 1-10）+ 检索评分（recency+importance+relevance）+ **反射**（重要性过阈值→综合成高层结论，可再反射）+ 分层规划（日计划→块计划→动作）
- 自发组织出情人节派对与信息扩散——"LLM 社会可行"最强证据
- **消融实验**：去掉反射 → 短期行为连贯，但数小时后主题忘记/人格漂移/规划失灵——记忆+反射+规划三者缺一不可
- 已知坑：importance inflation（需严格 rubric）、反射会编造（需引用具体记忆）、流膨胀（用小模型批量评估）

### RimWorld LLM 生态（与 infcanvas 最同构）
- **ClaudeStoryteller**：LLM 读殖民地实际状态（财富/防御/心情/食物）决策；三周期（小事件/大事件/叙事弧）；成本 $0.01–0.05/小时
- **Rimteller**：总结近况+全部可触发事件列表→LLM 只返回事件名+理由→游戏触发；**护栏：事件点数/频率由游戏控制，防"开局一万点袭击"；失败时 Randy 接管**
- **RimAI**：AI influence 滑块按比例混合 AI 与 vanilla；响应缓存；无效输出回退 vanilla
- **RimMind 全家桶**（2026 开源）：Core=异步请求队列（timeout/429/502 重试、过期丢弃）+ JSON 强制 + 28+ 项上下文过滤器；Memory=三层记忆（活跃/存档/暗记忆）；Advisor=AI 扮演小人决策→Actions 执行库；Personality=每日 LLM 评估注入 Thought 影响心情，**玩家投票塑造后续评估**（神谕影响 LLM 上下文的直接先例）；Dialogue=拦截事件生成上下文对话，效果注入 Thoughts/关系
- 整个生态共同原则：**LLM 只做"选择/决策"，执行与数值永远由确定性系统负责**

### 2025–2026 行业现状
- Gigax（开源）：本地低延迟 NPC 运行时 + 微调小模型
- NVIDIA ACE Game Agent SDK（2026 Beta）：on-device SLM
- Mantella / LLMUnity / UnrealGenAISupport：STT+LLM+TTS 接入引擎的通用管线
- GDC 2026：36% 从业者用 GenAI 工具，仅 5% 用于玩家-facing；AI NPC 在"期望膨胀期"，成熟预计 2028-2030

## 5. 共通启示（喂给 design 的结论）

1. **信仰/社会产出 = 干预预算**：神谕影响不应免费，由信众活动产出，教堂=信仰生产点+影响半径锚点，距离衰减
2. **拒绝全知**：神谕信息来自教区情报流（滞后、可能失真），未建教堂区域=盲区
3. **重复干预边际递减**：同一教义反复降下，信众习惯化——意图失真的放大器
4. **善意慢、恶意快但反噬**：毁灭性干预见效快但摧毁社会；过度慷慨也催生贪婪战争
5. **神只改目标层不改行为层**：方向性/概率性目标偏移，执行永远交给确定性层
6. **历史 = 仿真日志，不是事后编故事**：事件结构化记录（实体/地点/因果链），LLM 只做叙述润色
7. **生成时先跑零玩家策略游戏**：seed 生成后确定性模拟数百年历史，废墟/旧战场/仇敌来自仿真
8. **因果约束检查器**：LLM 事件先过"不能与已有历史矛盾"的校验，防悬浮叙事
9. **意义链**：文化从地形/资源推导（植被→疗法→宗教→方言→纹章），不是独立随机
10. **世界状态图**：战争后果用"条件→覆盖状态"表达（首领死亡→城镇易主），LLM 只改条件，确定性层触发
11. **休眠区先结算**：玩家离线/远走时区域不静止，宏观结算异步发生，回归后从传闻得知
12. **战争经济驱动**：打仗消耗物资→价格信号→生产扩张→支撑更大战争；劫掠补给线是合法战术
13. **所有势力同一套规则**：NPC 与玩家遵守相同物理/经济规则
14. **统一角色模型 + 关系网络 + 低成本意图表达**：CK3 证明这是自主社会的密码，不是复杂 AI
15. **物流可视化可诊断**：全局物流视图/供需热力图，瓶颈=干预锚点
16. **"LLM 慢决策 + 确定性快决策"是当前唯一主流解**：Rimteller/RimMind/AI Roguelite 三个独立实践同构验证
17. **失败回退链是第一公民**：排队→超时→熔断→确定性默认决策；暴露"AI 参与度"参数
18. **三层记忆是硬要求**：记忆流+反射+规划缺一不可（Smallville 消融实验）；注意 importance inflation 与反射编造两个坑
19. **上下文打包可观测可配置**：常驻（Plot Essentials 式）+ 关键词触发（Story Cards 式）两类；28+ 项过滤器省 token
20. **神谕编码为结构化约束**：目标/禁令/权重而非自由文本，防 prompt 注入、便于回退
21. **大 prompt 小结构化输出**：意图系统天然符合 token 价格结构；语义缓存 + 低峰批量 API 可大幅降本
22. **AI 参与度参数**：让玩家/存档可控 LLM 故障对文明的影响，防坏档
23. **叙事压力调节事件类型与主题**，不碰强度数值（点数/频率归游戏引擎）
