# Archived Gacha / Card-Draw Decision Engine (`archive/cards/`)

Per the RimWorld Parity & Multiplayer Overhaul specification:
- The legacy **Gacha / Card-Draw (`一切皆抽卡`)** pawn decision mechanism and **Tech Fragment Gacha Pool (`tech-pool.ts`)** have been archived in this directory (`archive/cards/`).
- Active gameplay now uses **RimWorld-standard Priority WorkGivers (1–4 manual work priorities)**, **Drafted RTS Direct Control (`R` key + Right-click orders)**, **Pawn 3-Skill Tactical Abilities (`MAX_PAWN_SKILLS = 3`)**, and **Research Bench deterministic progression**.
